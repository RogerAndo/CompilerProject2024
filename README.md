# CompilerProject2024

## Project Overview

This project is a small compiler designed as part of the curriculum for the course Formal Lanugages &Compilers at the Free University of Bozen-Bolzano (UniBZ).

## How to run it

Just type make in your terminal and the mini-c will be compiled.
To test input you can run `./mini-c < input.txt` or run it manually in your terminal by running `./mini-c`.
Keep in mind all variables have to be declared at the start of the programm.
